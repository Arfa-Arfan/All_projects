📌 Overview
This is a console-based Bank Management System implemented in C++ as a semester project. The system allows users to manage bank accounts with basic operations such as adding accounts, viewing details, searching, depositing, withdrawing, and deleting accounts. Data is stored persistently in a text file (bank.txt) to ensure user information is retained across sessions.

✨ Features
✅ Add New Account – Input name, account ID, balance, age, and address.

✅ Deposit Money – Add funds to an existing account.

✅ Withdraw Money – Deduct funds with balance validation.

✅ View All Accounts – Display all stored account details.

✅ Search Account – Find an account by ID.

✅ Delete Account – Remove an account from the system.

✅ File Handling – Save and load data using bank.txt.

✅ Error Handling – Prevents duplicate IDs, invalid inputs, and insufficient balance.

🧠 Concepts Applied
Object-Oriented Programming (OOP) using struct

File I/O (fstream)

Arrays for data storage

Control structures (loops, switch-case)

Functions and modular programming
